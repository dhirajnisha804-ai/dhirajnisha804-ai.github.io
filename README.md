# Derma Desk

Dermatology cases, prescriptions, medicines and Rx templates — as an installable Android app.

- **Web app:** https://dhirajnisha804-ai.github.io
- **Android APK:** https://dhirajnisha804-ai.github.io/DermaDesk.apk (backup: https://github.com/dhirajnisha804-ai/dhirajnisha804-ai.github.io/releases/latest/download/DermaDesk.apk)

Shared medicines and templates sync from Firebase (only the owner can edit).
Patients, photos and scores stay on each phone.

Folders: `www/` the app (published by GitHub Pages) · `android/` the APK shell · `tools/` build scripts.
